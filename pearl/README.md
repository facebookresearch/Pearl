# Pearl

Pearl is a production-ready reinforcement learning (RL) AI agent library
developed by the Applied Reinforcement Learning team
(oncall `reinforcement_learning`) and open-sourced as
`facebookresearch/Pearl`.

This folder holds the Pearl Python library: the agent API (`api/`),
policy learners (`policy_learners/`), replay buffers (`replay_buffers/`),
history summarization (`history_summarization_modules/`), safety modules
(`safety_modules/`), environment helpers (`user_envs/`), utilities
(`utils/`), tests (`test/`), and usage tutorials (`tutorials/`).
